# Поиск объявлений услуг Авито

По тексту запроса и его фильтрам решение выбирает **до 50 объявлений** из корпуса услуг. Для этого собираются кандидаты с помощью TF-IDF по словам и частям слов, добавляются результаты BM25, а модель градиентного бустинга отбирает итоговые 50.

**Результат на платформе:** Recall@50 **0,728630**. Отправленный файл — [answer.csv](answer.csv). Как получены метрики и где решение ошибается — в [REPORT.md](REPORT.md); краткая история опытов — в [EXPERIMENT_LOG.md](EXPERIMENT_LOG.md).

## Файлы для работы

| Файл | Назначение |
|---|---|
| `solution.ipynb` | От данных до обученной модели и кандидатов TF-IDF |
| `predict_bm25.py` | Добавляет кандидатов BM25 и записывает итоговый `answer.csv` |
| `bm25.py` | Реализация BM25, используемая скриптом предсказаний |
| `run_notebook.py` | Необязательный запуск ноутбука из терминала вместо Jupyter |
| `validate_answer.py` | Проверка формата и идентификаторов ответа |
| `requirements.txt` | Версии библиотек проверочного запуска |

**Почему BM25 отдельно от ноутбука?** Он проверялся как дополнительный способ поиска кандидатов уже после обучения модели. Поэтому `solution.ipynb` сохраняет обученную модель и TF-IDF-индексы, а `predict_bm25.py` использует их и код из `bm25.py`, чтобы получить именно отправленный ответ. Если выполнить только ноутбук, получится вариант **без BM25** — это не тот файл, который получил 0,728630. Для загрузки уже готового `answer.csv` скрипты не нужны; они нужны для воспроизведения. `run_notebook.py` и `validate_answer.py` лишь упрощают запуск и проверку.

Предыдущие ноутбуки, ответы и пакеты сдачи лежат в [experiments](experiments). Исходные Parquet и вычисленные индексы не публикуются: `data/` и `outputs/` исключены из Git.

## Как воспроизвести

1. Положить `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` в папку `data/`.
2. Создать окружение Python 3.12 и установить зависимости:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Из корня проекта выполнить команды по порядку:

   ```powershell
   .\.venv\Scripts\python.exe -X utf8 run_notebook.py
   .\.venv\Scripts\python.exe -X utf8 predict_bm25.py
   .\.venv\Scripts\python.exe -X utf8 validate_answer.py answer.csv
   ```

Ноутбук можно выполнить и в Jupyter с чистого ядра вместо первой команды. Полный проверочный запуск ноутбука занял около 12 минут; с этапом BM25 ориентир — **15–20 минут** на этом компьютере. Нужны несколько гигабайт оперативной памяти. Внешние API не используются.
