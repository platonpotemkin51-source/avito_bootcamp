# Архив опытов

Здесь сохранены промежуточные версии, чтобы было видно развитие решения. **Для запуска и сдачи используйте файлы из корня проекта.**

| Папка | Что внутри |
|---|---|
| `notebooks/` | Исходный, учебный и расширенные ноутбуки на 6000/10 000 запросах |
| `answers/` | Ответы первой версии и модели на 10 000 группах без BM25 |
| `docs/` | Старые отчёты, заметки и метрики baseline |
| `runners/` | Скрипты исторических запусков, включая полный эксперимент BM25 |
| `submissions/` | Снимки первой и финальной сдачи, а также ZIP-архивы |

Исторические скрипты ссылаются на старые пути в корне проекта и оставлены для изучения. Для воспроизведения актуального решения они не нужны. Крупные индексы и логи запусков остались в `outputs/`, который не отслеживается Git.
