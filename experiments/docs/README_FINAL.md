# Поиск объявлений услуг для Авито

Решение возвращает до 50 `item_id` для каждого запроса. Основной конвейер: два TF-IDF-индекса по корпусу, четыре канала поиска кандидатов, модель отбора на 10 000 обучающих группах. Дополнительный BM25 расширяет список кандидатов перед той же моделью.

Готовый файл для отправки — `answer.csv`. Его формат проверяется по обоим файлам бенчмарка. Исходные Parquet не входят в комплект: положите `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` в папку `data` рядом с ноутбуком. Все вычисления локальные, внешние API не используются.

## Файлы

- `solution.ipynb` — полный расчёт из исходных данных без готовых индексов и моделей; создаёт `answer.csv` для метода без BM25 и сохраняет модель с индексами в `outputs/final/`.
- `predict_bm25.py` — добавляет глобальных и локальных BM25-кандидатов, применяет ту же модель и создаёт `answer_bm25.csv`.
- `bm25_experiment.py` — функции BM25 и код отдельного локального сравнения методов.
- `validate_answer.py` — проверяет запросы, число объявлений, повторы, формат и принадлежность корпусу.
- `REPORT.md` — описание метода, локального эксперимента, метрик и ограничений.
- `requirements.txt` — версии библиотек проверочного запуска.

## Запуск

Нужен Python 3.12. Установите зависимости из `requirements.txt`, затем из каталога проекта запустите:

```powershell
python run_notebook.py
python predict_bm25.py
python validate_answer.py answer_bm25.csv
```

На компьютере, где команда `python` указывает на неработающий WindowsApps, используйте `./.venv/Scripts/python.exe` вместо неё. Можно также открыть `solution.ipynb` в Jupyter и выполнить ячейки по порядку с чистого ядра. Для варианта BM25 после этого запускается `predict_bm25.py`. Файл `answer_bm25.csv` можно переименовать в `answer.csv` перед отправкой; в комплекте файл уже назван `answer.csv`.

Ноутбук обучается на 10 000 группах запросов, выбирает метод на dev из 500 групп и оценивает его на отдельном test из 500 групп. При полном эксперименте новая модель получила 0,7900 на dev и 0,7943 на новом test. С кандидатами BM25 получено 0,7920 и 0,7983 соответственно. Полный запуск из исходных Parquet повторно дал тот же файл `answer_bm25.csv` побайтно; он совпадает с приложенным `answer.csv`. Пользователь подтвердил, что именно этот файл получил на платформе **Recall@50 = 0,728630**; прежний результат был 0,717977. Подробности — в `REPORT.md`.
